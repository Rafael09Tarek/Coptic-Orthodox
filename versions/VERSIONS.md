# 🕰️ سجل نسخ الموقع · Version history

هذا السجل يعرض نسخ الموقع بالترتيب الذي رُفعت به، من النسخة الأساسية إلى الأحدث.
الجدول يلخّص كل نسخة في سطر، وتحته **التفاصيل** نسخةً نسخة.

**لفتح نسخة قديمة وهي شغّالة:** اضغط «افتح» في عمودها. (يعمل بعد تفعيل GitHub Pages على المستودع.)

**كيف كُتب هذا السجل:** الأوصاف مستخرجة من مقارنة كود الملفات ببعضها (البيانات والعناصر والوظائف والأنماط وتعليقات المطوّر داخل الكود). لم تُفتح النسخ في متصفح لتجربتها، فالأوصاف تعكس ما في الكود، ومظهر كل نسخة وسلوكها الفعلي لم يُختبرا.

الاسم القديم هو اسم الملف الأصلي قبل إعادة التسمية.

- نص مخفي لقارئات الشاشة برقم السؤال، ونقل التركيز عند الانتقال بين حالات اللعبة.
- شريط الروابط: تمرير أفقي مع تلاشٍ عند الحافة يدل على وجود المزيد.
- شاشة نهاية اللعبة بحد أقصى 130 نقطة.
