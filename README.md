## ✨ About the project

**Coptic Orthodox** brings two projects together in one website:

- **Spiritual Capsule** — short spiritual capsules, organized by topic, with multi-part series.
- **Chapter Journey** — a Bible reading path that moves through the Scriptures chapter by chapter.

Everything is presented from a Coptic Orthodox perspective, in a calm and easy-to-read experience.

## 🌿 What you'll find

| | |
|---|---|
| 📚 **Capsules** | Spiritual capsules in themed sections, with connected series |
| 📖 **Bible & faith** | Biblical stories, doctrine, Church history, rites, and tradition |
| 🗓️ **Feast archive** | Church feasts, fasts, and commemorations on an interactive timeline |
| 🎮 **Games** | A Bible knowledge challenge and the "Who Am I?" game |
| 🔎 **Search** | Quick search across the capsules |
| ❤️ **Favorites** | Save capsules on your own device and come back to them |
| 🎲 **Random capsule** | Discover something new with one tap |
| 🌗 **Light & dark** | Two themes, in navy and gold |
| 📱 **Any screen** | Designed for phones, tablets, and desktops |

## 🌐 Languages

The interface is available in **Arabic, English, French, and German**.
The published capsule and Bible content is primarily in Arabic. See each language page for details.
